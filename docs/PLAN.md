## Frozen cross-track contract

1. **control_api_v2.py** (dashboard track creates): new module exposing expanded
   control/telemetry endpoints. Public surface: class `ControlAPIv2(cfg)` with
   `.endpoints` dict path→handler, plus `.register(server)` attaching handlers to
   a ThreadingHTTPServer. Dashboard track defines it and can change it freely;
   rewrite track integrates it in orchestrator.py (register alongside existing
   ControlHandler) once dashboard track reports it stable. If rewrite merges
   before dashboard is done, rewrite keeps existing ControlHandler untouched.
2. **AI provenance naming** (SETTLED — rewrite track, verified 2026-08-07):
   AI provenance is a REAL first SRT cue `00:00:00,000 --> 00:00:01,500`
   `[AI-generated by ASRSub]` (config `AI_MARKER_CUE`, default on; marker end
   bumps to just before the first dialogue cue when it starts < 2s). Bare
   header lines are skipped by players (ffmpeg srtdec.c, VLC subtitle.c) and
   SRT has no comment syntax. On-disk files are plain `{stem}.{lang}.srt`
   (no `.ai` suffix): Bazarr ignores uploaded filenames anyway (subliminal
   writes `{video stem}.{lang alpha2}.srt`), and `.ai` in filenames would only
   confuse content-sniffing. Known limitation (guessit): Indonesian `id` is
   NEVER auto-detected (parses as episode_title) — Bazarr's existing-file scan
   falls back to content-sniffing, which is expected; do NOT add `.ai` back as
   a workaround. Upload provenance metadata: none — the Bazarr upload
   endpoints have no comment/history field (verified in live swagger.json).
3. **SDH placeholders**: keep the `(Lirik lagu)` style. Rewrite may extend the
   placeholder set (e.g. `(SFX)`) only as a config-driven list, never hardcoded.
4. **Public interfaces rewrite track must preserve** (dashboard/pctl depend on
   them): `load_config()`, `post_chat()`, `chat_translate_batch()`,
   `halt_on_error()`, `guard_foreign_lines()`, `sanitize_lines()`, `write_srt()`,
   control API routes `/status /config /pause /resume /run-once /wake /health`,
   env keys in `~/.config/asr-pipeline/pipeline.env` (BAZARR_URL, BAZARR_API_KEY,
   SONARR_URL, SONARR_API_KEY, ASR_URL, TRANSLATE_BASE, TRANSLATE_MODEL,
   (default Gemma model: `/home/user/Documents/Tools/llama-cpp-turboquant/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q6_K_P.gguf`),
   CONTROL_API_KEY, TARGET_LANGS, MAX_EPS_PER_RUN). Signatures may change ONLY
   with a note in the merge commit.
5. **Never commit**: pipeline.env, state.jsonl, refine_state.jsonl, last_error.json,
   error_history/, __pycache__, .venv, selfheal_fix_spec_r*.md.

  whisper path only when ASR_BACKEND=sensevoice (whisper path untouched).
  VAD recipe empirically validated on PC (Frieren S02E01 180s slice, funasr

  `vad_kwargs={"max_single_segment_time": 5000, "max_end_silence_time": 400,
  "speech_pad_ms": 150, "min_speech_duration_ms": 250}` passed at AutoModel()
  CONSTRUCTION — never raw kwargs to inference() (crashes with
  chunk_size=None → frontend.fs NoneType). funasr 1.4.0 `res[0]["sentence_info"]`
  does NOT exist; the working path is generate(output_timestamp=True,
  merge_vad=False) + per-window char timestamps + bucket chunks into fsmn-vad
  windows. 400ms max_end_silence splits inside rapid dialogue (gaps 300-900ms)
  → 41% sub-1s fragments; neither the doc's 200ms rule nor _merge_tiny's
  0.6s-gap rule resolves them. Rewrite implements `_min_dur_postpass`:
  extend to 1.0s when the gap allows (≥150ms after extension), else merge
  with the closer neighbor (tie → previous) capped at 6.0s, else drop the
  fragment (last resort, unreachable in practice) — never emits <1s cues.

    start, then the file is truncated (atomic rewrite). skip → episode
